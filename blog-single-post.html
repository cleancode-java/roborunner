🚀 Robo Runner – 2D Platform Game Development

A fast-paced platformer built in Scratch focused on reaction, timing, and progression.

🧠 Overview

Robo Runner is a 2D platform game developed as a personal game design project using Scratch. The goal was to create a fast and engaging experience where the player must react quickly, avoid enemies, and survive increasingly difficult levels.

🎮 Core Gameplay

The player controls a robot that automatically moves forward. The gameplay focuses on jumping, climbing, and avoiding obstacles at the right moment. The difficulty increases progressively, making each level more intense than the previous one.

⚙️ Key Features

  • 🧩 Multiple enemy types with unique behaviors
  • 💎 Collectible treasures and scoring system
  • ❤️ Life system with survival mechanics
  • 🪜 Platform & ladder navigation
  • 📈 Progressive difficulty system
  • 🔊 Sound effects & feedback system

⚠️ Development Challenges

The biggest challenge was balancing difficulty — ensuring the game is challenging but still fair and playable. Another challenge was designing enemy behavior patterns that feel dynamic but remain learnable for the player.

🧪 What I Learned

This project improved my understanding of game design principles such as progression systems, player feedback loops, and interaction design. It also strengthened my ability to structure logic and create engaging gameplay using simple tools like Scratch.
